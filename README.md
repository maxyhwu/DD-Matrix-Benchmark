## Quantum Circuit Benchmark Set for Decision Diagram-Based Quantum Simulator

This benchmark set consists of common quantum circuits from three individual open-source benchmark sets, including [AutoQ](https://github.com/fmlab-iis/AutoQ/tree/main), [MQTBench](https://www.cda.cit.tum.de/mqtbench/), and [VeriQBench](https://github.com/Veri-Q/Benchmark).
